# Li&Chat 用户指南

Li&Chat 是基于 Li&Pass 统一账号的小圈子即时通讯：登录一次即可和好友、群成员收发消息、
传文件、语音、投票与 1:1 音视频通话。

## 登录与账号

- 首次访问点击「使用 Li&Pass 登录」，跳转门户授权后自动回到聊天界面；本地不保存密码。
- 头像/昵称/邮箱来自门户资料并自动同步；在「编辑资料」中修改的昵称、简介与头像不会被
  门户资料覆盖（邮箱仍随登录同步）。
- 「登录设备」可查看当前会话并撤销其他设备；「退出登录」会同时结束门户会话。
- 「通知设置」可开关桌面通知（页面后台时提醒，首次开启需授权）。

## 添加好友

1. 顶部搜索框按昵称或邮箱搜索用户（切到「消息」可搜聊天记录）。
2. 点击「添加好友」填写附言（可选，200 字内）发送申请。
3. 对方在侧栏「好友申请」接受后成为好友；右侧「好友推荐」可一键添加、刷新换一批。
4. 聊天头部铅笔按钮可设置备注名（仅自己可见，展示优先于对方昵称）；垃圾桶按钮可删除好友
   （解除关系，聊天记录保留）。

## 聊天

- 点击好友或群进入会话：Enter 发送、Shift+Enter 换行、Ctrl/Cmd+Enter 也可发送。
- 消息支持：回复（引用条）、转发（单条或多选批量）、收藏（个人菜单「我的收藏」）、
  表情回应、编辑（5 分钟内）、撤回（5 分钟内）、删除（仅自己视角）。
- 输入框：😊 表情面板、📎 附件（支持多选/拖拽/粘贴图片）、🎤 按住录音、剩余字数提示。
- 已发送消息显示「已读」（单聊）或「N 人已读」（群，点击可看名单）；断线自动重连并补拉
  错过的消息；发送失败的消息可点「重试」。
- 未发送内容自动保存为草稿，切换会话后回来仍在。

## 群聊

- 群主可建群并邀请好友（初始成员必须为好友）；成员上限 200。
- 群公告、群头像、改名、邀请/移除、设为管理员、转让群主由群主/管理员维护。
- 「禁言」针对普通成员；被禁言后输入框禁用，解除后恢复。
- 「文件」区聚合群内文件与语音，可直接下载。
- 群主可「解散群聊」（二次确认，永久删除），成员可「退出群聊」。
- 📊 发起投票：2–10 个选项、可多选；成员点击选项投票/改票，创建者或管理员可结束投票。

## 通话与通知

- 聊天头部电话/视频按钮发起 WebRTC 1:1 通话（仅好友间；媒体点对点，服务端只中转信令）。
- 「通话记录」查看最近通话（未接/拒绝/接通）。
- 铃铛通知中心聚合好友申请、@提及、禁言/角色变更/群解散，可一键全部已读。

## 搜索与整理

- 「用户/消息」双模式搜索；消息命中点击会打开对应会话并定位高亮该条消息。
- 会话行 📌 置顶、🔕 免打扰（灰徽标仍计数）、🗄️ 归档（底部「已归档」区可恢复）。
- 侧栏「筛选会话」按名称/摘要实时过滤。

## 数据与帮助

- 「导出数据」下载自己的 JSON 档案（资料/好友/群/可见消息/收藏），不含他人不可见内容。
- 「关于」显示版本信息；「快捷键」列出键盘操作（Ctrl/Cmd+K 搜索、? 帮助、Esc 关闭）。

## 常见问题

- **消息发不出去/被限流**：检查右上角连接状态；提示 429 表示操作过频，稍后重试。
- **图片/文件打不开**：附件仅会话参与者可查看；换浏览器确认登录态。
- **桌面通知不弹**：浏览器权限被拒绝时，在站点设置中重新授权。
- **对方离线**：消息正常落库，对方上线/重连后可见；呼叫离线会记「未接」。
